# ব্লুপ্রিন্ট: সাজানোর নিয়ম (ব্যবহারকারীর নির্দেশ, ৩ অক্টোবর ২০২৬)

ব্যবহারকারী বারবার প্রম্পট না লিখে **ব্লুপ্রিন্ট ডকুমেন্টের ভেতরেই সরাসরি বদল/সিদ্ধান্ত** দিতে চান। তাই বাংলা ব্লুপ্রিন্ট বানানোর সময়:

- প্রতিটা সিদ্ধান্ত/ফিচার **টেবিলের সারি** হবে, যেখানে ব্যবহারকারী ঘরে সরাসরি লিখতে বা dropdown বাছতে পারেন। কলাম: বিষয়, বর্তমান অবস্থা, সিদ্ধান্ত, প্রাধান্য, মন্তব্য।
- **Status dropdown**: প্রস্তাবিত, অনুমোদিত, বাদ, পরে, করা হয়েছে।
- **খোলা প্রশ্ন** আলাদা অংশে `- [ ]` চেকলিস্টে, যাতে ব্যবহারকারী উত্তর লিখে টিক দেন।
- প্রতিটা বড় অংশের শেষে "আপনার বদল/মন্তব্য" ঘর বা কমেন্টের জায়গা।
- ব্যবহারকারী ডকুমেন্টে কমেন্ট করলে সেটাই নির্দেশ: উত্তরে সেই কমেন্টের থ্রেডে জবাব দিয়ে ডকুমেন্ট আপডেট করতে হবে।
- ভাষা বাংলা, শুধু প্রয়োজনীয় টেকনিক্যাল শব্দ ইংরেজিতে।
- ডকুমেন্ট বানানো শুরু হবে শুধু ব্যবহারকারী "বানাও" বললে। নোট: `docs/blueprint-notes.md`।
